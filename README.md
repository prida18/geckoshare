# <img src="assets/logo.png" width="48" align="center"> GeckoShare

GeckoShare is a fast, fun, and secure peer-to-peer file sharing tool that works over your local network. No internet required, no cables needed—just feed the Gecko!

## ✨ Features
- **Instant Local Sharing**: Share files between PC, Mac, Android, and iOS instantly.
- **Secure Access**: Protected by a dynamic 4-digit security code.
- **QR Code Connection**: Just scan the QR code in your terminal or web UI to connect.
- **Real-time Updates**: See how many devices are connected and get instant file notifications.
- **Premium UI**: Modern, glassmorphism design with a cute animated gecko mascot.

## 🚀 Getting Started

### Prerequisites
You'll need Python 3.7+ installed on your machine.
Open CMD to install this setup. And if you want to close this setup press - "Ctrl + C"

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prida18/geckoshare.git
   cd geckoshare
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the server:**
   ```bash
   python server.py
   ```

### 📱 How to Use
1. Once the server starts, it will show a **Local IP** and a **QR Code** in your terminal.
2. Scan the QR code with your phone or visit the link on another computer.
3. Enter the **Security Code** shown in your terminal.
4. Drag and drop files onto the Gecko to share them!
